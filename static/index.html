太空碎片接近预警与规避协调

服务已启动。使用 JSON API 创建接近事件、记录来源、评估风险，并把规避指令与运营方回执接成一条链。

接口

GET  /health
GET  /api/state
GET  /api/items
GET  /api/items/{id}
POST /api/items
POST /api/items/{id}/sources
POST /api/items/{id}/actions

规避指令链

approve        协调员批准规避方案与窗口（开始/结束）
issue_command  协调员下发指令，同一物体同一时间只能有一条在途指令，窗口重叠返回 409
receipt        运营方回执：executed 或 failed（失败需填 reason，退回协调）
retry_command  协调员重试失败指令，沿用同一条指令，不重复占窗口
reschedule     协调员调整规避窗口
resolve        协调员结案（需已执行回执）
report_revision 新观测重算等级，不再占优的指令作废并释放窗口

事件详情返回 commands（指令状态、占用窗口、回执状态）；GET /api/state 返回全部在途指令的占用窗口。
